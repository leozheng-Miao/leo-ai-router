# LeoAI Router 前端重构视觉 Demo 交付要求

## 1. 项目定位

LeoAI Router 是一个面向开发者、个人用户和小团队的 AI 模型中转平台。平台核心价值不是普通聊天工具，而是“统一接入多家模型、智能路由、会员权益、积分消耗、API Key 管理和可观测运营”。

视觉 Demo 必须体现以下产品语义：

- 一个账号统一使用 DeepSeek、通义千问、智谱、OpenAI、Gemini 等模型。
- 聊天模型按会员等级和每日额度控制使用。
- 图片生成主要消耗积分，GPT / Gemini / OpenAI / Google 图片模型需要会员权限。
- 所有模型应该可见，但不可用模型要显示锁定态和升级提示。
- 后台管理要体现模型、供应商、插件、用户、角色权限、健康状态和成本统计。
- 用户侧要弱化旧 token 资产概念，突出会员、积分、使用趋势和账单。

## 2. 交付目标

生成一组可用于后续前端重构的高保真静态 Demo 图。Demo 图不需要完全可实现，但必须能作为 Vue 3 + Ant Design Vue 重构时的视觉参考。

每张图必须清晰表达：

- 页面信息架构。
- 核心操作入口。
- 关键状态，包括会员态、锁定态、加载态、生成中、健康状态、支付摘要等。
- 统一视觉语言，包括导航、卡片、表格、按钮、标签、图表、弹窗和抽屉。

## 3. 全局视觉风格

### 3.1 产品气质

- 专业、克制、现代、开发者工具感。
- 更像 Cursor、Vercel、Stripe Dashboard、OpenAI Platform 的运营后台，而不是营销型官网。
- 页面要适合长时间使用，强调信息密度、扫描效率和操作确定性。
- 不要做成大面积插画、炫酷赛博风、游戏风或纯宣传海报。

### 3.2 色彩要求

- 主色：中性深色文字 + 稳定蓝色操作色。
- 辅助色：绿色表示健康/成功，橙色表示额度/警告，红色表示异常/失败，紫色只用于 reasoning / 高级模型标识。
- 背景：浅灰白或轻微冷灰，内容区清晰分层。
- 禁止整页被紫色、蓝紫渐变、深蓝、黑金、棕橙或单一色系主导。
- 可以使用少量柔和渐变，但只能用于品牌标识、小型状态区或首页重点模块。

### 3.3 布局要求

- 控制台页面优先采用“左侧导航 + 顶部状态栏 + 主内容区”的结构。
- 首页可以使用顶部导航，但首屏应立即展示产品本体：模型路由、代码接入、调用统计和控制台入口。
- 页面最大内容宽度建议 1280px 至 1440px。
- 卡片圆角不超过 8px。
- 不要出现卡片套卡片的视觉堆叠。
- 工具型页面要紧凑，不要使用过大的 hero 字号或过多空白。

### 3.4 字体与文案

- 主体 UI 使用中文，技术名词保留英文，如 API Key、SSE、OpenAI、Gemini、DeepSeek。
- 文案要短，避免长段说明。
- Demo 中的数字和数据要像真实平台数据，不要使用 lorem ipsum。
- 图像生成可能不擅长精确中文小字，因此所有关键文字应尽量简短、大号、排版清楚。

### 3.5 组件语言

统一使用以下组件风格：

- 图标按钮用于复制、下载、刷新、删除、查看、设置。
- Segment 控件用于“套餐订阅 / 购买积分”“自动路由 / 固定模型 / 成本优先”等模式切换。
- 标签用于模型供应商、会员等级、健康状态、锁定状态。
- 表格用于管理后台，表格必须有筛选区、状态列、操作列。
- Drawer 用于账单、详情、历史记录。
- Modal 用于创建 API Key、选择模型、确认支付。
- 图表用于每日消耗趋势、模型调用占比、成功率和成本走势。
